# 上交所 IPO 审核时序全量追踪器
> 零幻觉、防反爬、支持横向拍平的自动化本地湖仓 (SSE IPO Timeline Tracker)

## 痛点与破局
上交所的科创板与主板 IPO 审核历史数据，在前端页面上呈现为动态树且分布碎片化。其背后的异步 XHR 甚至需要多级隐蔽接口交互才能还原一家企业的完整生命周期。手工盘点极度耗时，且容易遗漏节点。

本项目是一个开箱即用、**专为量化团队与投研数据工程师设计的数据抓取集群**。它不仅能全自动执行两级探测（大盘名录锚定 -> 详情历史下钻），更能将在纵向生长的审核节点**横向拍平**，生成一张立即可用的结构化 CSV 宽表：
`[企业名] | [受审ID] | [已受理周期] | [已问询周期] | [上市委结果/日期] | [提交注册日期]...`

## 核心架构特性
- **防脑补与架构强校验 (Zero-Hallucination Schema)**: 第一原则是不产生假数据。核心处理器全面接入 `Pydantic`。一旦 JSON 返回异样、字段缺失或为 `Null`，管道将被强制阻断并拦截报错。绝不向最终宽表塞入任何由补全逻辑瞎猜的脏维度。
- **高可用抗风控引擎 (Anti-Scraping Resilience)**: 采集器内部封装了 `Tenacity` 的指数级退避重试网络，外加动态随机停顿（0.5s~1.5s）。极大程度降低 IP 被目标服务器侦测或临时阻断的风险。
- **本地微型湖仓分离 (Automated File Routing)**: 零库表配置依赖，一行脚本即可按日期自动挂载 `.data_pipeline` 目录树。原始网络响应 (Raw JSON) 与最终清算报表 (Processed CSV) 实现双轨落盘，支持最高等级的复核审计。

## 快速集成与起步

首先，请确保您拥有 Python 3.9+ 并在目标环境中执行：
```bash
# 1. 安装核心运行组件
pip install requests pandas pydantic loguru tenacity

# 2. 启动全量爬取集群
python src/main.py
```

> **执行提示**：系统将在后台构建并调度大盘抓取。运行日志（包括报错阻断快照）会实时保存在 `.logs/` 中，成品的 `.csv` 宽表将被直接输出至 `.data_pipeline/processed/今日日期/`。

## 代码拓扑解耦
系统抛弃了混乱的面条式爬虫脚本，完全遵循三层独立数据流控制：
- **`src/collector.py`**: 纯粹的网络驱动级联引擎。负责 HTTP 隧道与重试包装。
- **`src/processor.py`**: 洗练中心。包含 Pydantic 强校验器与将树状数组横向揉平的 Flatten 算法。
- **`src/storage.py`**: I/O 操作中心。管理文件目录快照逻辑。
- **`src/main.py`**: 初始化调度主脉络与 Loguru 日志挂载。
